### Seven Systemic Failure Clusters Still Blocking Production Readiness
1. **Broken Live Streaming Across Almost All Providers (`CRITICAL`)**: `OpenAICompatibleAdapter._chat_internal()` (`openai_compat_adapter.py:638-702`) and `AnthropicAdapter._build_payload()` (`anthropic_adapter.py:429-437`) never put `"stream": True` in the outbound JSON body (affecting OpenAI, Anthropic, Gemini, Copilot, LM Studio, llama-server, MLX, OpenRouter, Groq), causing `consume_sse_stream()` to discard non-SSE JSON and return `{"ok": True, "text": ""}`. Separately, `OllamaAdapter.generate()` (`ollama_adapter.py:531-570`) returns `{"ok": True, "text": "meta"}` on streaming HTTP/connection errors, and `decode_sse_line()` (`streaming.py:274-296`) wedges permanently on any malformed UTF-8 byte.
2. **Failed Runs Reported as Success & Completion Contract Bypass (`CRITICAL`)**: `_build_loop_exit_response()` / `_build_success_response()` (`inference_loop_rounds.py:212-263`, `inference_loop_responses.py:187-256`) omit `ok=False`/`status`/`error` when `final_state["run"]["status"] == "failed"`, causing CLI headless exit `0` and HTTP `/task` `COMPLETED` on failed/rolled-back runs. Meanwhile `completion_contract.py:284-295` treats any succeeding `bash` command (`ls`) as mutating evidence and returns `is_complete=True` *before* checking missing named deliverables or unpaid red-green test debt.
3. **Shell Parser Differentials, Broken Background Sandbox & Fail-Open Pipeline Gates (`CRITICAL`)**: `split_shell_segments()` (`bash_security.py:236-274`) treats `\n` as whitespace while `/bin/bash -c` (`_bash_exec.py:180`) executes line 2 as an unvalidated command; `bash(run_in_background=True)` double-appends `cmd_parts` (`_bash_exec.py:204` + `_bash_safety.py:851`), breaking every sandboxed background command and leaking `.sb` profiles + host env; `SAFE_COMMANDS` admits `find -exec`/`-okdir`, `awk`, `tar`, GNU `sed` `e`/`w`, and `zip`; and security gates in `pipeline/preflight.py`, `pipeline/permissions.py`, `tool_execution_pipeline.py`, `tool_hooks.py`, and `permission_context.py` fail open on exceptions.
4. **Untrusted Workspace Trust-Boundary Bypasses (`CRITICAL` / `HIGH`)**: Untrusted workspace configs bypass MCP workspace trust via `"source": "global"`, `"trusted": true`, or global name collision (`config_loader.py:350-366`, `mcp/manager.py:335-357`); `.codingAgent/verify.yaml` runs arbitrary allowlisted binaries without checking `is_trusted()` (`verification_helpers.py:274-370`); `load_project_settings()`, `get_small_model()`, `get_project_tool_overrides()`, and `web.ssrf_allowlist` read untrusted workspace config; crafted GGUF metadata enables shell injection in `local-launch --script` (`local_launch_cmd.py:65-89`).
5. **Live TUI Deadlocks, Crashes & Unreachable Controls (`CRITICAL` / `HIGH`)**: `/undo` deadlocks on non-reentrant `_history_lock` (`_bridge_session.py:130-148`); `StreamView.stop_stream()` executes `await` while holding a `threading.Lock` (`stream_view.py:107-127`); `/queue` replaces `deque` with `list` and crashes `_drain_message_queue()` (`_slash_model_commands_mixin.py:441-446`); `RoleTransitionEvent` raises `ModuleNotFoundError`; `BashBlock` crashes on `[/...]` markup; `SessionScreen` traps keyboard focus on `#sessions_search` (making `f`/`r`/`d`/`n` unreachable); `SettingsScreen._do_save()` sets active models to `"none"`; and `/provider`/`/model` leave `orch.adapter` stale without normalizing history.
6. **Subagent Worktree, Plan Mode, Rollback & `--private` Data-Integrity Gaps (`CRITICAL` / `HIGH`)**: `delegate_task(mode="worktree")` mutates the main repository instead of the worktree (`subagent_tools.py:235, 284`); `plan_exit` lets the LLM self-approve Plan Mode without user confirmation (`post_hooks.py:251-266`); plan-mode suspension drops sibling tool calls (`frontier_loop_node.py:413-423`); `RollbackManager._persist_snapshot_disk()` strips `"encoding"` from binary snapshots (`rollback_manager.py:595-613`), corrupting binary files on reload/rollback; `ParallelWorktreeSession` (`--parallel`) deletes changes if `git commit` fails; and `--private` still writes to disk across 7 modules (`RollbackManager`, `SessionCostTracker`, `checkpoint_saver`, `change_log`, `distiller`, `sanitization`, `repo_indexer`/`session_store`).
7. **Unintegrated Subsystems & Evaluation/Server Hardening Gaps (`HIGH` / `MEDIUM`)**: `SymbolGraph`, `clamp_response_tokens()`/`response_reserve()`, `verification_helpers` validation command keys, `create_governor_from_gguf()`, `JsonlCheckpointSaver` LangGraph methods, `ToolExecutionService`, `scheduler` persistence/factories, and `src/core/logger.py` audit logging have zero live callers. ## 2. Architecture Strengths

1. **Deterministic 6-Stage `AgentRunner` & Strict Node Schemas** (`src/core/orchestration/runner.py:135-275`, `builder.py:28-72`, `state_schemas.py:99-279`): Native async pipeline (`initialize -> agent_loop -> [approval | verify | compact | finalize]`) with `recursion_limit`, `merge_or_replace_list`, and `CODINGAGENT_STATE_SCHEMAS_STRICT=1` validation on every node boundary.
2. **Unified `ToolRegistry` & Real Type-Introspected Schemas** (`src/tools/_registry.py:95-480`, `src/tools/_tool.py:129-162`, `registry_builder.py:13-16`): Single source of truth across `build_registry()` and `example_registry()`, guarded fail-closed `ToolRegistry.call()`, `inspect.unwrap()` discovery, and `typing.get_origin`/`get_args` OpenAI JSON schema generation with `"additionalProperties": False`.
3. **Structured Pre-Write Safety & Pass-Ordered Fuzzy Edit Engine** (`src/tools/_file_io.py:139-187`, `_workspace_guard.py:57-146`, `_edit_matcher.py:97-256`): `_pre_write_check()` enforces `.git`/secret/dangling-symlink/hardlink safety + workspace confinement + read-before-write; `_find_edit_match()` scans full-file passes in strict precedence order with ambiguity rejection and closest-match diagnostics.
4. **Canonical Tool Pipeline Ordering, Deterministic Reducer & Process-Group Sandbox** (`tool_execution_pipeline.py:103-245`, `tool_output_reducer.py:76-530`, `src/tools/sandbox.py:114-225, 563-640`): Alias normalization before permission checks, `PreToolUse` hooks strictly after `PermissionPolicy`, bounded pre-redacted `ToolOutputStore`, macOS Seatbelt write-canary probe, and `start_new_session=True` + `os.killpg(..., SIGKILL)` timeout enforcement.
5. **Anthropic Prompt-Cache Boundary, `TurnGroup`-Atomic Compaction & DoS-Bounded GGUF Parser** (`static_prompt_parts.py:317-416`, `compact_node.py:31-276`, `gguf_header.py:27-35, 193-250`): Static prompt prefix cleanly separated from dynamic context, atomic `[assistant(tool_calls), tool...]` compaction with nonce-fenced `<compaction_summary>` envelopes, and `O_NOFOLLOW`/16 MiB bounded GGUF inspection.
6. **Multi-Lane Bounded `MessageBus`, Side-Effect-Free `CircuitBreaker` & Strict CLI Parsing** (`messaging/bus.py:67-683`, `circuit_breaker.py:46-95`, `src/cli/arg_parser.py:11-16, 490`): Isolated `TELEMETRY`/`RELIABLE`/`ORDERED` lanes prevent event starvation; `CircuitBreaker` inspection is read-only; CLI rejects typos in security flags.
7. **Server Pre-Validation Auth, Constant-Time Comparisons & Working Textual 8.1.0 Mixin Dispatch** (`src/server/app.py:143, 165-328`, `task_endpoints.py:71-171, 292-424`, `tui/tui_src/ui/app.py:700-735`): Pre-Pydantic `Depends(_require_admin_auth)`, `hmac.compare_digest()`, approved workdir roots, bounded task queue, and verified 60-handler `@on` registration in Textual 8.1.0 with valid CSS across all screens/widgets.

## 5. Major Missing Capabilities

1. **Working Streaming Across Cloud & Local OpenAI-Compatible/Anthropic Providers**: Because `stream=True` is omitted from outbound JSON payloads (`CRIT-01`), live streaming is effectively broken on every adapter except Ollama (and Ollama streaming itself misreports HTTP errors as `"meta"`).

## 12. Performance Bottlenecks

1. **Eager TUI Import & Background Polling Thread on Every Short-Lived CLI Call (`MEDIUM`)**: `src/main.py:138` calls `_check_tui_imports()` (importing `textual` + `tui_src`) even for headless commands like `context-report` or `status`, and `get_config_reloader()` starts a 1-second SHA-256 disk-polling daemon thread on short-lived headless runs.
2. **Uncached Tokenizer & Negative HF Lookup Overhead (`MEDIUM` / `LOW`)**: `MessageManager._estimate_tokens()` calls `tiktoken.encoding_for_model("gpt-4")` uncached on every message (`message_manager.py:94-110`); `tokenizer._get_hf_tokenizer()` (`tokenizer.py:44-92`) does not cache negative lookups, retrying disk loads on every `count_tokens()` call for `qwen3`/`gemma`/`llama`/`deepseek`.
3. **Aggressive Unconditional Tool-Output Pruning & Over-Clamped Quota (`MEDIUM` / `LOW`)**: `prune_stale_tool_outputs(..., stale_after_turns=3)` runs on every turn even at `<10%` context utilization, forcing models to re-read files and re-run commands; `ContextBuilder` over-clamps `conversation_quota` via `min(max_tokens - 2100, ...)` even when actual system prompt tokens are `< 2100`; and `ContextBuilder` fails to pass `conversation_quota` to `ContextController`, dropping useful retrieved snippets prematurely.
4. **Local Runtime Context & Apple Silicon KV Calibration Gaps (`MEDIUM`)**: `LmStudioAdapter` drops `num_ctx`/`kv_cache_quant` and sends redundant legacy `functions` schemas (doubling tool schema payload!); `LlamaServerAdapter` omits `get_loaded_context_length()` so live `n_ctx` is never discovered; Apple Silicon `HARDWARE_PROFILES` set `vram_gb == ram_gb` (0% OS reserve); and `clamp_response_tokens()`/`response_reserve()` are completely unwired (`provider_context.py:267-316`).
5. **Scheduler Single-Thread Head-of-Line Blocking (`HIGH`)**: `_scheduler_loop` blocks synchronously on `fut.result(timeout=300)` inside its single loop thread and quantizes wakeups to `heartbeat_interval` (60s), stalling all other jobs and shutdown.
6. **Unbounded Metric Dicts & `Orchestrator` Memory Leaks (`HIGH` / `MEDIUM`)**: `ConfigReloader._callbacks` holds strong references to every `Orchestrator` forever; `approval_gate._GateRegistry` leaks timed-out gates and event-loop refs; `metrics._DROPPED_EVENT_COUNTERS` and `_CORRECTIVE_PROMPT_COUNTERS` grow unboundedly; `SWEBenchRunner` leaks tempdirs and `Orchestrator` thread pools; `headless_runner.py` never calls `orch.close()`.
